รายละเอียดแต่ละขั้นตอน
📥 Input — การรวบรวมข้อมูล
แหล่งข้อมูล
นักศึกษาที่ต้องการเปิดวิชาเรียนพิเศษ (ปี 4 หรือภาคค่ำ)
ข้อมูลดิบที่รับเข้า
รายวิชาที่ต้องการ — ตรวจสอบก่อนว่าไม่มีในตารางปกติ
ข้อมูลส่วนตัว — ชื่อ รหัสนักศึกษา ระดับชั้น สาขาวิชา
ช่องทางรับข้อมูล — Google Form ของสำนักส่งเสริมวิชาการและงานทะเบียน
⚙️ Process — การประมวลผล
ขั้นที่ 1 — ตรวจสอบ & จัดหมวดหมู่
เจ้าหน้าที่ตรวจสอบเงื่อนไข: นักศึกษาปี 4 หรือภาคค่ำ และจำนวนผู้ขอครบเกณฑ์
ขั้นที่ 2 — วิเคราะห์ & ตัดสินใจ
สายวิชาพิจารณาอนุมัติ และจัดหาอาจารย์ผู้สอนสำหรับรายวิชานั้น
ขั้นที่ 3 — รอผลสรุป
รวบรวมคำร้องทั้งหมด 1–2 สัปดาห์ หลังหมดเขตรับเรื่อง เพื่อสรุปผลรายวิชาที่เปิดได้
📤 Output — การแสดงผล
สารสนเทศที่ได้
ประกาศผลการยื่นคำร้อง — แจ้งผลอนุมัติ/ไม่อนุมัติแก่นักศึกษา
การดำเนินการต่อเนื่อง (กรณีอนุมัติ)
ลงทะเบียนชำระเงิน — นักศึกษายืนยันสิทธิ์และชำระค่าเรียน
ติดต่ออาจารย์ผู้สอน — นัดหมายเพื่อเริ่มการเรียนการสอนจริง
การเชื่อมโยงระหว่างขั้นตอน
1
INPUT

นักศึกษายื่นคำร้องผ่าน Google Form

ก่อนกรอกฟอร์ม นักศึกษาต้องตรวจสอบว่ารายวิชาที่ต้องการ ไม่มีในตารางเรียนปกติของภาคการศึกษานั้น ข้อมูลที่กรอกได้แก่ ชื่อ-รหัสนักศึกษา รายวิชา และเหตุผลที่ต้องการเปิด ข้อมูลนี้ถือเป็น "ข้อมูลดิบ (Raw Data)" ที่ยังไม่มีการประมวลผลใดๆ

2
PROCESS

สำนักวิชาการรับข้อมูลและตรวจสอบเงื่อนไข

ข้อมูลดิบจาก Google Form ถูกส่งต่อมายังเจ้าหน้าที่ เพื่อตรวจสอบว่าผู้ขอและรายวิชาเป็นไปตามเกณฑ์ (เช่น เป็นนักศึกษาปี 4, ภาคค่ำ, มีจำนวนนักศึกษาขั้นต่ำ) นี่คือจุด เชื่อมต่อระหว่าง Input → Process

3
PROCESS

สายวิชาพิจารณาและจัดหาอาจารย์

เมื่อผ่านการกรองเบื้องต้น สายวิชาจะวิเคราะห์ทรัพยากร (อาจารย์ ห้องเรียน เวลา) เพื่อประกอบการตัดสินใจ ระบบรอรวมผลทุกคำร้องและใช้เวลา 1–2 สัปดาห์ เพื่อสรุป ทำให้กระบวนการนี้เป็น Batch Processing

4
OUTPUT

ประกาศผลและนักศึกษาดำเนินการต่อ

ผลจากการประมวลผลถูกแปลงเป็น "สารสนเทศ" ในรูปประกาศผล ซึ่งนักศึกษาสามารถนำไปใช้ตัดสินใจลงทะเบียนและชำระเงินได้ทันที นี่คือจุด เชื่อมต่อระหว่าง Process → Output

5
OUTPUT → FEEDBACK

ลงทะเบียนและติดต่ออาจารย์ (Feedback Loop)

การที่นักศึกษาลงทะเบียนสำเร็จและติดต่ออาจารย์เป็นผล Feedback กลับสู่ระบบ — ยืนยันว่าหมู่เรียนพิเศษนั้นมีผู้เรียนจริง และข้อมูลนี้จะกลายเป็น Input ให้ฝ่ายวิชาการวางแผนภาคการศึกษาถัดไป
