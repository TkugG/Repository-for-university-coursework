🗺️ แผนผังการไหลของข้อมูล (Visual Data Flow)

ระบบบันทึกและจัดการสิ่งที่ต้องทำ (Note & To-Do App) - สถาปัตยกรรม Decoupled MVC

1. ฝั่งหน้าบ้าน (Frontend)

เพื่อนรับผิดชอบดูแล
index.html View
หน้าจอเว็บหลัก: ฟอร์มสร้าง/แก้ไข, การ์ดสีพาสเทล 5 สี, แถบหมวดหมู่ และปุ่มค้นหา
assets/js/app.js Client Script
ดักจับตอนผู้ใช้กดปุ่ม ยิงคำขอ fetch() ไปหลังบ้าน และวาดการ์ดขึ้นจอ

2. ฝั่งหลังบ้าน (Backend)

คุณรับผิดชอบดูแล (PHP OOP)
api/notes.php Controller
เคาน์เตอร์รับคำขอ GET, POST, DELETE ตรวจข้อมูล เซฟไฟล์ภาพ แล้วสั่ง Model
models/Note.php Model
สมองจัดการโน๊ตหลัก: คำนวณ เพิ่ม ลบ แก้ไข ค้นหา และแจ้งเตือน
models/TodoItem.php Model
สมองจัดการข้อย่อย: ติ๊กถูกขีดฆ่า เพิ่มหรือลบข้อย่อย (Single Responsibility)
models/Database.php Connection
กุญแจต่อ MySQL ผ่าน PDO ซ่อนรหัสผ่านเป็น private (Encapsulation)

3. ที่จัดเก็บข้อมูล (Storage)

ฐานข้อมูลและไฟล์
MySQL Database database.sql
เก็บข้อมูล 3 ตาราง:
• categories (หมวดหมู่)
• notes (โน๊ตหลัก)
• todo_items (รายการข้อย่อย)
uploads/ Folder
เก็บไฟล์รูปภาพที่ผู้ใช้อัปโหลด โดยถูกสุ่มชื่อใหม่ด้วย uniqid()
สายพานจริง: "เมื่อผู้ใช้กดบันทึกโน๊ตใหม่บนหน้าเว็บ"
ข้อมูลเดินทางเป็นลำดับ 6 ขั้นตอนตามนี้ จากหน้าจอวิ่งไปลงฐานข้อมูลแล้วเด้งกลับมา
1
ผู้ใช้กดปุ่ม "บันทึกโน๊ต" บนหน้าจอ index.html + app.js
JavaScript ดึงค่าจากฟอร์ม (หัวข้อ, ข้อความ, หมวดหมู่, รูปภาพ, สีการ์ด) ใส่ลงใน FormData แล้วสั่งยิง fetch('api/notes.php', { method: 'POST' })
2
เคาน์เตอร์รับเรื่อง และตรวจสอบความถูกต้อง api/notes.php
Controller ตรวจสอบว่ามีหัวข้อครบไหม หากมีไฟล์รูปภาพส่งมา จะใช้ uniqid('note_', true) สุ่มชื่อไฟล์ใหม่ แล้วสั่งย้ายไปเก็บที่โฟลเดอร์ uploads/ จากนั้นส่งข้อมูลต่อให้ Model
3
เรียกใช้งานคลาส Note ตามหลัก OOP models/Note.php
คลาส Note ขอยืมตัวเชื่อมต่อฐานข้อมูลจาก Database.php ผ่าน Constructor (หลัก Dependency Injection) เพื่อเตรียมเขียนคำสั่ง SQL
4
บันทึกข้อมูลลงฐานข้อมูลอย่างปลอดภัย MySQL Database
ส่งคำสั่ง INSERT INTO notes ... โดยใช้ Prepared Statements (bindValue) ป้องกันการโดนแฮก SQL Injection 100% ข้อมูลลงตารางจริงใน phpMyAdmin
5
ตอบกลับผลลัพธ์เป็นมาตรฐาน JSON api/notes.php -> app.js
หลังบ้านส่งผลลัพธ์กลับเป็น JSON เช่น {"success": true, "id": 5} ผ่าน Header application/json
6
หน้าเว็บรีเฟรชการ์ดสีใบใหม่ขึ้นจอทันที index.html
หน้าเว็บรับ JSON แล้วสั่งวาดการ์ดใบใหม่สีพาสเทล พร้อมปุ่มแก้ไข ถังขยะลบ และ Checkbox ให้ผู้ใช้เห็นทันทีแบบไม่ต้องกดรีโหลดหน้าเว็บ!

จุดพูดเอาคะแนนเต็มตอนพรีเซนต์:

"ระบบของเราแบ่งหน้าที่ตามหลัก Decoupled MVC ชัดเจนครับ หน้าบ้าน (View) ยิงคำขอผ่าน Fetch มาที่เคาน์เตอร์ API (Controller) และมีสมอง Model (PHP OOP) คอยจัดการฐานข้อมูล MySQL ข้อมูลเดินทางเป็นสายพาน 6 สเต็ป ทำให้โค้ดเป็นระเบียบ ปลอดภัย และทดสอบแยกส่วนได้ง่ายครับ"
