# PHP OOAD OOP

# เครื่องมือ Programing Language
- ใช้ PHP เป็นหลัก
- ใช้เครื่องมือภาษา ตามความเหมาะสม โดยจะถามก่อนใช้

# เขียนโค้ดง่ายๆ สไตล์นักศึกษา IT ห้ามใช้ท่ายาก
- เป็นมือใหม่ณปัจจุบัน ยังเขียน PHP ไม่เป็น
- โดยใช้ภาษาตามความเหมาะสมกับงานที่ทำ แต่ต้องเสนอก่อนลงมือทำ

# อย่าพึ่งเขียนโค้ดถ้ายังไม่สั่งให้เขียน
- ขั้นแรกที่สุดเราต้องวางแผนกันก่อนจะเริ่มทำงานจริงตามหลัก OOAD
